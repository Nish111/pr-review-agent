# ADR-0007 · Default: four specialists, no code search, calibrated threshold 0.84

- **Status:** accepted, 7 Nov 2026 (S6)
- **Evidence:** `.genesis/decisions/S6-default-configuration.md`, `eval/findings_rung4.md`

## Context
Rung 4 tested whether the bot may post on its own at ≥ 90% precision, choosing the threshold leave-one-PR-out.

## Decision
No code search by default; a comment posts only if its calibrated score ≥ 0.84; everything else goes to the approval queue.

## Consequences
8/8 posted right on the golden set (95% range 0.68-1.00); with search, no threshold qualified. Search stays in the code, off.
