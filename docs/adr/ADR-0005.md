# ADR-0005 · Golden set: 14 seeded + 5 real PRs

- **Status:** accepted, 21 Oct 2026 (S4)
- **Evidence:** `.genesis/decisions/S4-golden-pr-source.md`, `golden/`

## Context
Every rung needs the same yardstick, including clean PRs to catch false alarms.

## Decision
10 planted bugs + 4 clean PRs in a demo app; 5 pallets/click PRs whose bugs click itself named; labels committed before scoring; real PRs reported per PR, no percentage.

## Consequences
Comparable numbers across rungs; small sample (stated everywhere).
