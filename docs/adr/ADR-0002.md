# ADR-0002 · Free LLM: openai/gpt-oss-120b on Groq

- **Status:** accepted, 21 Oct 2026 (S1)
- **Evidence:** `.genesis/decisions/S1-free-llm.md`, `reports/report.html`

## Context
Zero cost (kickoff Q1). Groq's free tier: 8k tokens/min, a daily token limit per model.

## Decision
Groq `openai/gpt-oss-120b`, temperature 0, ≤ 5,000 tokens per call; a different provider (Gemini) as the judge.

## Consequences
Rungs 2-3 cost $0; a full rung 3 arm took about one day of quota. About half the output tokens are hidden reasoning (M9).
