# ADR-0006 · The baseline is the lecture design, rebuilt where needed

- **Status:** accepted, 21 Oct 2026 (S5)
- **Evidence:** `.genesis/decisions/S5-baseline.md`, `STEP3_FIND_BASELINE.md`

## Context
No baseline code was supplied; `pr-review-agent.html` gives the design.

## Decision
Where a before/after number needs it, the lecture's design is rebuilt faithfully (`webhook_receiver/baseline.py`, `ingestion/baseline.py`) and run on the same tests.

## Consequences
Honest before/after comparisons; the rebuilds are ours, so their fidelity is a stated assumption.
