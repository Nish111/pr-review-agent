# ADR-0008 · One process, thread fan-out, shared token bucket (no LangGraph)

- **Status:** accepted, 27 Oct 2026 (matrix 04)
- **Evidence:** `FAILURE_MATRIX_04_SPECIALISTS.md`, `orchestrator/`

## Context
The lecture uses LangGraph to run four nodes in parallel with checkpoints. On the free tier, four parallel calls exceed 8k tokens/min.

## Decision
A thread pool runs the specialists; one token bucket spaces them; each specialist's answer is cached on its own (checkpoint per node); a failure leaves a partial review.

## Consequences
All 144 rung 3 calls were answered and runs resumed after quota stops without re-asking. 16 calls needed one transport retry, all in the no-search arm while it ran concurrently with the search arm: the bucket is per process, so two processes can still exceed the shared limit together (a known gap). Fewer moving parts; no graph visualisation.
