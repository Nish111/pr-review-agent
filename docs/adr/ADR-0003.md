# ADR-0003 · Local embeddings: bge-small (jina planned)

- **Status:** accepted 21 Oct, amended 26 Oct 2026 (S2)
- **Evidence:** `.genesis/decisions/S2-embedding-model.md`

## Context
Code search needs embeddings; paid APIs break Q1.

## Decision
`BAAI/bge-small-en-v1.5` on CPU, version pinned in the index. jina (code-trained) failed to load with transformers 5.

## Consequences
Click indexes in about 3 minutes. The vector lane finds the right neighbourhood, not the exact spot (matrix 03 §5).
