# ADR-0009 · Comments only; humans approve; the bot never approves or merges

- **Status:** accepted, 19 Oct 2026 (G0, invariant)
- **Evidence:** `docs/ARCHITECTURE.md` §4, `hitl/`, `github_client/`

## Context
The brief's outcome is not a replacement for a senior reviewer; irreversible actions belong to people.

## Decision
The GitHub client can read, comment and set a status, nothing else. Critical findings, partial reviews and uncalibrated comments go to the approval queue; disputes become labels.

## Consequences
Safe by construction (test K7); the cost is that a human has to work through the queue.
